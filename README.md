# 2Billion Dollar Music — V1

A responsive static website starter for 2Billion Dollar Music.

## Included
- Home / brand hero
- Music releases and play buttons
- Artist roster
- Studio booking section
- Contact section
- Mobile navigation

## Next production step
Replace placeholder WhatsApp/email details and connect real audio URLs. For the planned V1 admin system, add a secure backend/database for admin-only uploads, stream counters, artist profiles and booking records. Never put admin credentials in front-end JavaScript.

## Run
Open `index.html` in a browser or upload the folder to a static host.
